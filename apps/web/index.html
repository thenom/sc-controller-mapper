Star Citizen Keybinding Architect — HOTAS, HOSAS & XML Input Management Suite

Star Citizen Keybinding Architect (scbind.com) is a free, open-source web utility engineered for Star Citizen pilots using complex HOTAS, HOSAS, rudder pedal, and multi-panel flight simulator cockpits. Built specifically for Star Citizen's CryEngine-derived actionmaps.xml input architecture, it provides lossless XML editing, drag-and-drop joystick instance re-indexing, real-time HTML5 Gamepad hardware telemetry, and intelligent Master Modes conflict diagnostics.

Core Capabilities & Technical Architecture

  • Bypass the 4-Device pp_resortdevices Console Limit: Star Citizen's in-game console command pp_resortdevices cannot remap setups with more than four connected DirectInput controllers. When Windows reorders USB joysticks after a reboot or firmware update, this suite rewrites js1_, js2_, js3_, js4_, and higher device prefixes directly at the XML Abstract Syntax Tree (AST) level while updating <options type="joystick" instance="X"> hardware blocks in lockstep.
  • Lossless CryEngine XML Round-Tripping: Preserves axis inversions (invert="1"), custom deadzones, sensitivity curves, DirectInput ProductGUID attributes, primary <rebind> overrides, additive <addbind> concurrent inputs, and explicit unbind tags (<rebind input=""/>) so Star Citizen never silently reverts cleared actions to defaultProfile.xml defaults.
  • Master Modes (SCM / NAV) & Temporal Conflict Diagnostics: Evaluates over 50 Star Citizen action maps across a four-tier severity hierarchy. Automatically distinguishes harmless overlaps between mutually exclusive contexts (such as on-foot FPS vs. spaceship flight, or isolated cockpit Operator Modes like Mining, Salvage, Scanning, and Missile Operator) from fatal concurrent collisions and destructive hold/press conflicts (such as sharing a button with v_eject or v_self_destruct).
  • Live HTML5 Gamepad Hardware Inspector: Press any physical button, hat switch, or analog axis on your connected VKB Gladiator EVO, VIRPIL MongoosT-50, Thrustmaster T.16000M, or WinWing controller to immediately locate and edit every action bound to that physical input.

How to Import, Re-Index, and Export Star Citizen Keybindings

  1. Export your current profile in Star Citizen via Options → Keybindings → Advanced Controls Customization → Control Profiles → Save Control Settings, or locate your XML file under StarCitizen\LIVE\USER\Client\0\Controls\Mappings\.
  2. Click Import XML in the Keybinding Architect toolbar (or select one of the built-in Dual VKB EVO HOSAS, VKB Omni-Throttle OTA, or Thrustmaster T.16000M HOTAS starter templates).
  3. Use the Device Rack to drag and drop joystick instances (js1 ↔ js2), inspect or edit bindings in the Keybinding Matrix, and review the Conflict Diagnostics tab for fatal collisions or deprecated bindings.
  4. Click Export XML to download your clean, lossless profile and place it in your Mappings folder, then load it in-game via pp_rebindkeys layout_filename_exported.
